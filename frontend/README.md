# How to Run the Project Step by step

1. Go to backend folder then see the package.json file.
2. Then here the Debug run button at the fourth line.
3. Then click the button(up nodemon server.js) start the server.

               (or)

1. Open the terminal bar at the bottom, Go to the cd backend file path.
2. Then run the command npm run up.
